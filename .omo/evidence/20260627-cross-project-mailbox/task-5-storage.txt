## DESIGN NOTES (patterns cloned)
- Reservation = fs.rename to `.delivering-<id>.md` (atomic on POSIX), exactly like team-core/team-mailbox/reservation.ts
- ack = rename reserved (or plain) note into processed/<id>.md, like team-core ack.ts
- Atomic write = open(wx) temp in same dir + rename, like boulder/project-registry atomicWrite
- Note format = YAML front-matter + "---\n" delimiter + Markdown body via envelope/schema.ts serializeEnvelope/parseEnvelope
- assertPathWithinRoot + safeMessageIdFilename guard EVERY file op under coordination_notes/
- Stale reclaim 4-case logic (A history_confirmed -> ack; B dispatch_sent+in history -> confirm+ack;
  C dispatch_sent+absent past TTL -> return to unread + remove pending; D no entry -> return to unread)
- drainUnread = latest-per-supersede-chain, priority-desc then timestamp-asc; does NOT reserve, does NOT delete superseded
