DRAIN FLOW (one idle event)
---------------------------
1. falsy sessionId -> return early (no spawn, no inject)             [SAFETY B]
2. resolveActivePrimaryAgent(sessionId)
3. primary not in config.intake_eligible_agents -> return early (note stays unread)
4. getRegisteredProjects() as senders
5. per sender mailbox (coordination_notes/<senderId>/):
   a. reclaimStale(currentSessionMessageIds)
   b. drainUnread(max_notes_per_drain)
   c. per note:
      - digestStore.checkAndRecord -> isDuplicate => validateInbound(note, cfg, {duplicateLoop:true}) -> quarantine "duplicate-loop"
      - rateLimiter.checkRateLimit -> limited => skip (LEFT UNREAD, not quarantined)
      - validateInbound(note, cfg) -> invalid => quarantine(reason, detail) -> skip
      - reserve(messageId) -> undefined => skip (already reserved)
      - buildTriagePrompt(note, {projectDisplayName})
      - dispatchInternalPrompt({ mode:"async", input:{ path, body:{parts:[{type:text}]}, query } })  [no agent/model/variant]  [SAFETY A]
      - addDispatchSent({messageId, sessionId, reservedPath, dispatchedAt})
6. capped at max_notes_per_drain total injections per idle cycle
NOTE: ack is DEFERRED to reclaimStale()/history-confirm on a later cycle. The hook NEVER acks.
