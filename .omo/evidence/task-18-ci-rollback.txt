=== Known limitations in rollback ===
- Workflow file protection on GitHub: after rollback, if the upstream dev branch
  is later fast-forwarded to include workflow changes, the sync workflow cannot
  push those changes with the default GITHUB_TOKEN. Solution: provision a PAT
  (personal access token) and store as repo secret SYNC_PAT, then update the
  sync workflow to use `token: ${{ secrets.SYNC_PAT }}` in the checkout step.
- This is acceptable: rollback is for emergency recovery only. Long-term
  operation still requires the PAT provisioning as a follow-up.
